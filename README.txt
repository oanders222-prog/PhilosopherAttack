PHILOSOPHER ATTACK
Argument Arsenal: The Philosopher's Labyrinth

HOW TO PLAY

1. Extract the ZIP file before playing.
2. Open Philosopher-Attack.html in a modern web browser.
3. Keep an internet connection active so the philosopher portraits can load.

CONTROLS

W / S or Up / Down arrows: Move forward and backward
A / D or Left / Right arrows: Turn
Q / E: Sidestep
Mouse movement: Look around
1 / 2 / 3: Select an argument scroll
Click or Space: Use the selected argument
M: Toggle the map
Esc: Pause, resume, or exit to the title screen

GOAL

Collect argument scrolls and use the correct response against each of the
eight philosophers. You may carry only three arguments at a time. Each
unanswered attack removes 9 percent of your conviction. After defeating all
eight philosophers, retrieve the final key and find the illuminated exit.
